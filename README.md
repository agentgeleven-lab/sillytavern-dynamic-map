# SillyTavern 动态地图 · 0.4.0

独立的可收起地图悬浮窗，无第三方运行依赖，无需构建。顶部六页：查看地图、调整地图、地图规则、AI生成地图、地图模板、设置。

## 安装与更新

在酒馆「扩展 → 安装扩展」中输入：

```text
https://github.com/agentgeleven-lab/sillytavern-dynamic-map
```

已有安装可更新扩展后刷新。手动安装请把完整文件夹放入用户扩展目录，manifest.json 应位于插件根目录，只安装一份。更新前可导出已保存地图备份。

## 查看与调整

- **查看地图**只显示已保存地图。点击地点或途经点，在下方查看说明、邻接地点、相对方位、道路类型、距离、单/双向和所选通行方式的预计时间。
- 拖动空白平移，滚轮缩放。「拖动后回归」重新适配全部节点，不改当前位置或变量。拖动标题移动悬浮窗，方向键也可移动标题。窗口会自动限制在可见范围。
- **调整地图**编辑草稿。选择地图节点编辑名称、说明、固定选项的地点类型；可新增/删除地点或修改当前位置。
- 路线选择起点、终点及 16 方位之一，终点自动按方位排列。每段图上长度相等；不能同时满足的闭环或重叠会被拒绝。
- 地点默认锁定。点亮「✓ 允许拖动地点」后，拖动地点会选择其**直接相连邻居中离指针最近的一个**作锚点，显示 16 方位并吸附；松手保留锚点连接、断开该地点的其他连接，其他地点保留。红色虚线表示准备断开的路。无连接地点需先添加路线才能拖动。
- **途经点**显示为小圆点，可作为远途的中间节点或岔路口。可单独新增，或在已有道路上「插入途经点」。插入后原来一段变为两段，总距离增加；继续添加途经点可延长路途，每个途经点可连接多个地点。删除途经点会断开它关联的道路，不自动桥接两端。
- 地点、路线表单中的「应用」把填写内容写入草稿。只有「保存地图」才更新查看页和已保存状态接口；「放弃草稿」撤销未保存调整。切换聊天会在本页面内保留各自草稿，刷新页面会丢弃草稿。

## 规则、模板与生成

- **地图规则**设置每段实际距离、距离单位和通行方式/速度，默认走路 5 公里/小时。每段时间 = 距离 ÷ 速度。每张地图有独立规则。暂无自动寻路或旅途计时器。
- **设置**添加、更名或删除地点类型。正在使用的类型不能删除；可先修改地点类型。新增途经点会自动恢复途经点类型。
- **AI生成地图**调用酒馆当前 `generateRaw` 接口生成 JSON 草稿。模型须已在酒馆配置；生成失败、返回无效地图或生成期间聊天/草稿变化，都不会覆盖地图。生成后检查草稿再保存。此功能尚未在真实酒馆模型上实测。
- **地图模板**在本浏览器保存命名模板，载入到草稿；支持导出已保存地图、导出草稿、导入不超过 5 MB 的 JSON。载入模板或导入会替换未保存草稿，可先导出草稿。模板不会自动跨设备同步。

## 保存与接口

保存写入当前 `chatMetadata.dynamicMapV1`，先留浏览器恢复副本，再调用酒馆 `saveMetadata()`。同步失败会提示；在模板页可重试同步或导出。未同步副本可在同一浏览器恢复。已同步缓存不会覆盖聊天元数据或复活同名新聊天。

聊天切换时读取独立文档。角色头像/群聊 ID 与聊天名构成作用域，浏览器数据另按插件用户命名空间隔离。没有聊天时只读。损坏的存档不会被示例覆盖，请先在模板页导出原始数据，再导入有效地图草稿并保存。

公共入口仍为 `window.SillyTavernDynamicMap`：核心状态和摘要订阅只读到已保存地图；外部 `applyUpdate` 属于直接更新已保存状态的集成接口。外部更新与未保存草稿冲突时，草稿保存会被拒绝，需要先导出草稿或放弃后重新调整。暂不支持多个页面编辑同一聊天时的合并。

小白X、状态栏均不是核心依赖；目前提供接口，尚未自动接入这两个插件，也未注册 Tool Calling。graph 已渲染，hex/grid 仅预留协议。

## 结构

```text
src/core/protocol.js     地图协议、引用及规则校验
src/core/spatial.js      16 方位、等长布局、吸附、路线说明
src/core/draft.js        草稿隔离、冲突检查、显式保存
src/core/store.js        已保存状态、原子更新与订阅
src/adapters/chat.js     聊天绑定、保存与恢复副本
src/ui/panel.js          六页悬浮窗和表单
src/ui/graph.js          SVG、相机平移、节点拖动预览
src/ui/floating.js       悬浮位置与折叠偏好
src/integrations/api.js  可选变量/状态栏/AI 接口
```

旧 editor.js/navigation.js 为未加载的历史模块，不参与新版界面。
