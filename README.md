# SillyTavern 动态地图 · 0.12.1

无第三方运行依赖、无需构建的地图悬浮窗。顶部六页：查看地图、调整地图、地图规则、AI生成地图、地图模板、设置。

## 安装与更新

在酒馆「扩展 → 安装扩展」中输入：

```text
https://github.com/agentgeleven-lab/sillytavern-dynamic-map
```

已有安装可更新扩展后刷新。手动安装请把完整文件夹放入用户扩展目录，manifest.json 应位于插件根目录，只安装一份。更新前可导出已保存地图备份。

## 节点连线地图的拖动逻辑

先打开角色卡的聊天，再进入「调整地图」并勾选「允许拖动地点」。

- 按住地点后可自由拖动，节点与道路预览跟随指针。
- 靠近**任意地点**都会显示它的 16 方位，虚线圈表示松手后的吸附位置，不限于原有邻居。
- 松手会吸附并连接最近的地点，断开被拖地点的其他旧连接；原地点全部保留。
- 远离所有地点时按松手坐标自由放置，并断开旧连接。
- 吸附半径为图上一段道路长度的 1.4 倍。已占用的方位会避让到最近可用方位；全不可用时给出提示。
- 继续连接其他道路，可以在「路线连接」中手动添加。手动吸附使用固定参考长度；自动布局可调整图上线长；真实距离在每条道路中单独填写，可留空。

这些操作都只影响草稿。只有「保存地图」后，查看地图和对外状态接口才使用新地图。切换聊天会在本页面保留各自草稿，刷新页面会丢弃未保存草稿。

## 简洁操作页

「调整地图」下方用按钮切换当前操作，不再同时展开全部表单：

- **移动地点**：拖动说明。
- **地点资料**：选择或新增地点，编辑名称、说明、类型，设置当前位置。
- **路线连接**：选择或新增路线，设置端点、16 方位、固定道路类型和单向/双向。
- **途经点**：单独新增，或在选中道路中插入。插入把一段变两段，已有距离均分且总距离不变。途经点可作岔路口。
- **删除**：删除地点及关联路线，或仅断开选中路线。未保存时可放弃草稿恢复。

「查看地图」只显示已保存地图。点击地点查看说明、相邻地点、方位、距离、道路类型、通行方式、预计时间和单向限制。拖动空白平移，滚轮缩放，「拖动后回归」适配所有节点，不改当前位置。

## 地图规则与界面设置

「地图规则」内的按钮分别管理距离、通行方式、地点类型、道路类型。类型可新增、更名、删除；正在使用的类型需要先替换后才能删除。旧存档的自定义类型会保留。新增途经点会恢复途经点类型。默认走路速度为 5 公里/小时；时间按每条道路距离 ÷ 速度计算，距离为空时不估算，无自动寻路或旅途计时器。

「设置」中的界面选项立即生效，不修改地图和变量：

- **在消息末尾显示小型地图按钮**：控制消息末尾的「🗺 地图」按钮。点击按钮会在该消息下方展开完整地图窗口，再次点击关闭。消息内可查看、调整、保存地图，并使用规则、生成、模板和设置六页。消息窗口与悬浮窗共用当前聊天的地图草稿，关闭窗口不丢草稿；不代表历史消息时点的地图，不把内容写入聊天正文。
- **界面主题**：青绿、深蓝、浅色。主题与按钮开关保存在界面偏好中。

## 独立地图生成 API

在「设置 → 地图生成 API」配置：

1. 勾选「使用独立 API 生成地图」。
2. 填写 API 地址、API 密钥和模型名称。支持兼容 Chat Completions 的服务；地址可填基础地址、`/v1` 地址或完整的 `/chat/completions` 地址。
3. 可调整最大输出长度和超时时间，默认 4096 tokens、120 秒。总超时对酒馆模型与独立 API 都生效，包含素材读取阶段。
4. 点击「保存 API 设置」，再到「AI生成地图」生成。关闭独立 API 后使用酒馆当前模型。

配置只用于地图生成，不改酒馆的聊天模型。角色卡与世界书读取范围不变，生成结果仍需检查并「保存地图」。

密钥输入框使用密码显示。默认密钥只在当前页面会话中保留；可勾选「记住密钥（仅本浏览器）」保存到浏览器本地存储。地址、模型等配置独立保存在本浏览器。密钥不进入地图 JSON、模板、聊天元数据或模型提示词。「清除密钥」删除会话和本地保存的密钥。

请求从浏览器直接发送，服务必须允许跨域请求；此版不提供服务器代理。仅支持非流式 Chat Completions，不支持直接填写其他协议的地址。请求失败不会自动切换服务重试；HTTP 失败、网络错误、超时、空响应和截断输出都会提示且不会覆盖地图。

## AI 生成的读取范围

默认读取当前角色卡、角色主世界书、角色附加绑定世界书，以及当前聊天绑定世界书。没有绑定主世界书时兼容角色卡内嵌世界书。

可选 **“同时读取已开启的全局世界书”**：仅加入酒馆中当前已开启的全局世界书（可以未绑定角色），不会遍历全部已保存的世界书，也不会读取未开启的其他书籍。重复书籍去重；各书跳过禁用条目和空内容。读取完成后界面显示实际书名及字符数。此读取用于地图生成素材，不依赖聊天关键词触发。

读取接口参考 [SillyTavern 官方世界书模块](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/world-info.js)：主绑定使用角色 extensions.world，附加绑定使用 charLore，全局开关使用 selected_world_info。

仅在点击生成后读取素材并调用酒馆当前模型。超过 200,000 字符、书籍读取失败、聊天或草稿变化时不会覆盖地图；超长内容不会静默截断。生成结果先进入草稿，检查后再保存。当前仅支持单角色聊天，真实模型输出质量依赖模型及设定素材。角色卡与世界书不会被修改。

## 模板、保存与接口

模板保存于本浏览器，可命名存储或载入草稿。支持导出已保存地图、导出草稿、导入不超过 5 MB 的 JSON。载入/导入会替换未保存草稿，可先导出备份。

保存写入当前 chatMetadata.dynamicMapV1，先保留本地恢复副本，再调用酒馆 saveMetadata()。同步失败时可在模板页重试或导出。未同步副本可在同一浏览器恢复。已同步缓存不会覆盖聊天元数据或复活同名新聊天。损坏存档可先导出原始数据，再导入有效草稿并保存恢复。

公共入口为 window.SillyTavernDynamicMap；订阅和摘要读取已保存状态。外部 applyUpdate 仍直接更新已保存状态，若和未保存草稿冲突则拒绝草稿覆盖。暂不支持多个页面编辑同一聊天的合并。

小白X、状态栏不是依赖，现已提供变量桥接和原生 Tool Calling，详见后文。graph、hex、grid 均可显示、编辑与保存，支持父子地图导航。

## v0.6.2 生成等待与地图命名

生成页显示“读取角色卡与世界书 / 读取某本世界书 / 等待模型返回 / 检查地图”及已等待秒数。两种模型都受总超时控制，默认 120 秒，可在设置中修改并保存。点击“取消生成”会立即停止等待，迟到结果不会修改草稿。关闭窗口也取消该窗口的生成等待。

独立 API 会收到中止信号；酒馆内部请求能否真正终止由宿主决定，插件不调用可能影响正常聊天的全局停止操作。取消/超时不是模型服务已停止计算的保证。素材较大时可先取消，再减少启用的全局书范围或改用已配置的独立 API。界面写着“使用酒馆当前模型”时，独立 API 尚未启用。

初始示例名称改为“未命名地图”。旧聊天已保存的名字保持不变；在“调整地图 → 地图名称”修改、应用后保存即可。生成提示只使用中性的结构样例，不再把旧地图的沧州/龙门市内容当作示例，要求模型按角色和世界设定命名。模型仍沿用通用示例名时，使用“角色名称 · 地图”作回退名称。

## v0.6.5 道路资料
路线连接页可填写道路名称和可选距离，留空名称不显示道路标签。距离为空时不估算时间。自动布局下线段长度可变，实际道路距离不参与布局。旧存档的统一距离迁移到各条道路；新路默认无距离。规则页只保留距离单位，修改单位不会换算数值。插入途经点将已有距离均分，总距离不变。修改后仍须保存地图。

AI生成地图新增“为道路生成名称”，默认关闭。勾选时提示模型命名，不勾选时要求所有道路 name 为空。已有手动填写的名称不会因关闭选项而被删除。

## v0.6.5 距离生成与新增模式
AI 页的“为道路生成距离”默认关闭，新生成道路距离保持 null；勾选后要求模型按素材填写，估计值注明依据。新增按钮读取当前草稿、角色卡、选中的世界书及最近 30 条非系统聊天正文（最多 60000 字符，超限报错不截断），只合并新地点和道路，保留已有资料和当前位置。重复 ID、重复连接或无法满足固定地点与锁定方位的冲突会拒绝应用；生成期间聊天变化也拒绝应用。生成结果仍需保存。

## v0.7.0 自动布局

在“调整地图 → 自动布局 → 自动整理地图”整理当前草稿。支持闭环、分支、密集连接、独立区域及孤立地点，分散重叠节点，并尽量避开道路穿过无关地点。图上道路允许不同长度，真实距离、名称、通行规则和连接不变。未锁定的方位根据排布更新。

- 地点资料中的“固定此地点位置”保留该节点坐标，已固定地点也不能拖动。旧版 layout.fixed 只是计算坐标标志，不代表用户锁定；新锁定使用 layout.pinned。
- 路线连接中的“锁定此道路方位”保留其 16 方位扇区。该方向不要求线条精确落在扇区中心。手动新增路线默认锁定，可取消；已有未锁定路线先保留为布局偏好。
- 编辑路线、插入途经点及 AI 整图生成会自动整理布局；自动布局地图新增手动地点时保留旧点。AI 新增模式将原地点作为固定锚点，只安排新增位置和路线方位。
- 保存会使用预览坐标，不再恢复等长位置。所有操作先进入草稿，未保存不影响查看地图或对外变量。
- 固定地点或锁定方位互相矛盾时拒绝整次调整并提示，不删除地点或道路。可解除部分锁定后重试。
- 单图最多 250 个地点、1500 条道路。采用有界启发式排布，不能保证所有可行约束都能求解，也不保证完全无交叉；线条交叉不是路口，路口须显式添加途经点。超长地点名、道路文字可能仍需缩放或手动整理。

同时修复路线编辑回调错误引用生成模式变量的问题，并加入真实按钮操作回归。


## v0.8.0 六边形、方格与地图层级

在「调整地图 → 地图类型与层级」选择形态并应用，可将现有地图转换为节点连线、六边形或方格。格子大小仅用于显示，转换不修改道路距离、名称和连接。转换到格子会吸附到最近空格，并解除道路方位锁定；方位由格子位置计算，详情仍以 16 方位描述。

- 格子地图一格一个地点。允许拖动后，松手吸附到空格，保留全部道路；占用格与固定地点会提示，不覆盖其他地点。
- 地点资料、路线连接、途经点、当前位置、名称、距离和通行方式继续可用。格子之间可以连接长路，格子相邻本身不代表有路。
- 填写新地图名称、形态及入口地点，点击「创建子地图」。可多层嵌套，例如世界 → 城市 → 建筑，每层可使用不同形态。也可创建独立地图。
- 「进入」与「返回上级」切换地图；每张地图分别保留当前位置。入口可关联上级的具体地点，或整个上级地图。归属可以调整，但不允许循环。
- 删除空地图前需先调整子地图归属，至少保留一张地图；关联子地图的入口地点受到保护。
- 形态、地点和层级编辑都是草稿，需要「保存地图」；未保存时查看页不显示新增地图。浏览已保存地图不再使未保存草稿产生无意义的冲突。
- AI 完整生成只替换当前一张地图，保留其他层级；已有子地图入口缺失时拒绝应用。新增模式支持三种形态，保留旧地点。

v0.8.0 格子是地点布局底图；v0.9.0 已增加属性与涂色，尚无障碍格、格子寻路或自动跨层移动。空格不保存为大量地点，实际路程仍以道路资料为准。


## v0.9.0 格子属性与批量涂色

六边形或方格地图中，打开「调整地图 → 编辑格子」，点击一格设置区域类型、地形、行政归属、名称、说明和独立颜色。勾选「刷选格子」后按住鼠标拖过多个格子，松手后统一设置，点击「应用到选中格子」。多次刷选会累加选择，「清空格子选择」取消选择；「清除选中格子属性」只清除格子资料，不删地点或道路。单格点击重新选择，刷选关闭时拖动空白仍可平移。

「地图规则」新增格子区域类型、格子地形、行政区域。区域类型默认包含市区、郊区、乡村、荒野；地形默认平原、山地、森林、水域。目录可新增、修改名称和颜色、删除；正在使用的条目不能删除。行政区域可创建省 → 市 → 区，各格只引用一个目录条目，省名更改无需逐格改写。

未设置独立颜色时依次采用区域类型、地形、行政区域颜色。批量表单将所有显示属性统一覆盖到选中格子，空选项表示清除该属性。所有编辑先进入草稿，保存地图后才正式生效。查看页点击空格显示说明，点击地点仍查看地点资料。

格子属性独立于地点，拖动地点不会搬走地形或行政归属。地图转换形态时属性保留在相同 q/r 格子编号，图上外形和位置会变化；切换节点连线地图时暂不显示但仍保留。AI 完整生成与新增模式保留人工设置的格子属性，尚不自动生成地形。最多保存 10000 个有属性的格子，每类目录最多 500 项。通行属性、寻路与速度倍率留待后续实现。


## v0.10.0 统一导航与按层级生成

查看、编辑、规则和生成页共用地图选择栏，按完整父子路径区分同名地图，支持搜索。上方路径按钮和返回上级可快速切换；查看页点击地点后，在说明中选择「打开内部地图」。同一地点可以关联多张内部地图，独立世界及多层地图同时保留。

浏览范围现在仅是窗口状态，不写入聊天地图、不修改角色位置、不触发变量同步。角色位置显示为「世界 → 城市 → 建筑 → 地点」，父地图会在关联入口标记当前位置。在编辑页明确点击「设为当前位置」并保存，才改变角色所在地图及地点。各地图原有 currentLocation 继续保留为该地图的记录，只有 activeMap 对应实际角色地图。旧存档沿用此前 activeMap，不推测更早的真实位置。

保存按钮改为「保存全部地图调整」，列出有修改的地图；在地图间切换不会丢草稿。所有地图及入口关联一起保存，避免父子关系只保存一半。外部 API 修改角色地图时会与未保存草稿产生冲突保护。

AI 页新增「生成层级」：世界／大陆、国家／省份、城市／聚落、宗门／园区、建筑／地下城、自定义，各有独立范围提示词。层级与形态独立，生成不会因层级选择强制改变当前地图形态。模型收到目标名称、父级路径、入口地点说明、已知当前位置与必须保留的子地图入口。

- 「生成地图草稿」重新生成当前选择的地图，保留其他地图；页面明确显示替换范围。
- 「根据资料与聊天记录新增地点和道路」仍只追加当前地图内容。
- 「为选中地点生成内部地图」使用入口下拉栏选定地点，并单独选择形态，生成一张新子地图；不会覆盖已有内部地图，也不会移动角色。
- 成功后显示目标地图及地点/道路总数，结果先进入草稿。新增地图也须保存全部调整后才能在查看页使用。
- 「撤销本次生成」恢复整份生成前草稿，包含原有未保存编辑。在后续修改、再次保存或切换聊天后不能借此覆盖新状态；撤销不等于清除全部草稿。
- 生成中切换地图、聊天或修改草稿，会拒绝迟到结果。

本次未实现跨地图自动移动、出入口配对、寻路以及格子编辑的通用撤销/重做。不同层级的真实模型生成质量仍需在实际设定下验证。


## v0.10.1 查看页的内部地图入口

## v0.11.0 小白X变量与状态栏实际联动

同时更新动态地图和 [世界状态栏 1.8.2](https://github.com/agentgeleven-lab/world-status-hud)，刷新页面。地图设置新增联动开关：聊天变量摘要和状态栏位置默认开启，AI 位置更新默认关闭。

地图保存后，经酒馆 `/scripts/variables.js` 的 setLocalVariable 写入当前聊天的 JSON 变量「地图」。与 LittleWhiteBox 的变量命令及 2.0 系统使用同一存储。支持 `{{xbgetvar::地图.地点名称}}`、`{{xbgetvar_yaml::地图}}`。变量包含版本、地图与地点 ID/名称、层级路径、当前位置格子区域类型/地形/行政归属、可出发的已发现邻接路线。完整 maps/nodes/edges 不进入变量。未打开聊天或尚未保存示例时不发布；草稿与浏览不发布。已被其他内容占用的「地图」变量不会覆盖，设置页给出反馈。

状态栏新增独立的「当前地图位置」区域，点击按钮关闭状态栏窗口并打开角色所在地图。此区域直接读取地图公共接口，不修改「状态栏」变量，不混入其生成模板或历史记录。只安装一个插件也可继续运行；关闭地图的状态栏联动开关可隐藏该区域。

### AI 位置请求

需要启用小白X变量管理 2.0，并在地图设置开启「允许小白X提交位置更新」。从设置页复制联动提示词到自己的世界书；插件不会自动改写世界书。摘要是只读输出，请让模型只修改「地图移动请求」：

```text
<state>
地图移动请求: {"请求ID":"move-001","地图版本":123456789,"地图ID":"world","地点ID":"longmen_city"}
</state>
```

示例地图版本必须替换为当前「地图.地图版本」的数字，ID 必须来自实际地图。每次使用新的请求ID并完整赋值；不要只改其中一个字段。请求通过当前版本、目标存在/已发现/允许联动检查后，原子更新角色地图和地点，再重新发布摘要。关闭开关期间、切换聊天或初次加载时的既有请求不补执行；过期请求、重复执行及无效目标不应用。写入请求到处理约有 750ms 间隔。没有自动寻路、路线权限校验或时间推进：这是叙事位置更新入口，不是旅行执行器。

### 位置楼层记录

地图在当前聊天元数据中保存每楼层及回复分支的位置记录，用消息 extra ID 区分楼层，不改消息正文。删除后续消息、切换末尾回复分支后，恢复已记录的位置；无有效位置时清空当前位置。刷新后使用记录的楼层顺序继续检测。仅恢复位置，不回滚整张地图，若历史地点已被删除也不会重新造点。正常浏览旧楼层不会恢复位置。

设置页显示小白X接口和状态栏检测状态、同步/请求错误，并提供重试。读写与模块加载都校验聊天身份；一个适配器失败不阻止地图独立使用。宿主若未提供变量模块或保存接口，会显示未同步，不能把此状态当作成功。

接口依据：LittleWhiteBox 提供的 [变量管理 2.0 文档](https://docs.littlewhitebox.qzz.io/数据互动/变量管理2.0)，源码核对提交 `a6f9f6c9b8776723d08250d0863f9be2f48c7810` 中的 variables-core.js、var-commands.js。没有修改 LittleWhiteBox 源码或绕过它的变量规则。


## v0.12.0 原生 AI 动态更新与 Tool Calling

接入 [SillyTavern 官方 Function Calling 接口](https://docs.sillytavern.app/for-contributors/function-calling/)，由酒馆聊天模型真实调用注册工具并收到结构化结果。无需小白X，不解析正文中的伪工具标签。独立地图生成 API 继续用于生成页，不承接原生聊天工具。

1. 更新并刷新插件，打开角色聊天，先保存初始地图。
2. 在酒馆 AI 响应配置启用函数调用，使用支持工具的 Chat Completion 模型。设置页显示宿主注册与支持检测结果；接口存在不保证服务商具体模型一定调用。
3. 在地图设置开启「启用聊天中的地图工具」。可复制该区提示词到世界书，或在聊天中明确要求使用地图工具。
4. 默认变更进入共享草稿，到调整地图检查后「保存全部地图调整」。也可开启「自动保存 AI 地图更新」，校验通过后立即应用并触发原有变量与状态栏同步。「允许 AI 删除地点和道路」是独立开关，默认关闭。

工具有两个：`dynamic_map_query` 查询指定地图（省略 mapId 时查角色地图），返回所有地图层级索引、当前地图已发现且允许进入上下文的地点/道路、类型目录、规则及一次性 token；`dynamic_map_update` 携带 token、reason 和 operations 一次提交最多 30 项变更。

支持 add_node / update_node / remove_node、add_edge / update_edge / remove_edge、move。新增地点必须提供 name；新增道路必须提供 from/to。所有操作都指定 mapId 和 id；地点类型、道路类型来自规则目录。道路名称和距离可省略，默认空名称和未知距离。位置移动仅表示剧情已到达，不执行寻路、通行许可或时间结算。

查询返回的 token 只对当前聊天及当前保存/草稿版本有效。成功提交后失效，下一批须重新查询。人工编辑、保存或切换聊天会拒绝过期请求。未保存的人工草稿不会被自动合并或覆盖；AI 可以继续更新自己尚未被人工编辑的草稿。批量先校验、再布局、最后整体应用，任意项失败均不落地。graph 采用保留现有坐标的增量布局，hex/grid 放入可用格子，实际道路距离不参与布局。显式 graph 道路方位会锁定；与现有位置冲突时拒绝，格子地图方向由格位决定。

模型调用及结果保留在酒馆工具消息中。设置页可刷新最近处理结果。应用成功代表已进入地图保存流程，服务器同步成败仍以地图底部状态为准。不要同时通过旧「地图移动请求」重复处理同一次移动。

本版工具仅编辑已有地图内的地点/道路及角色位置；新建层级地图、格子属性/规则编辑仍使用原有界面。隐藏地点不会通过查询泄露，也不会由工具解锁。历史回退沿用位置记录，不回滚地点与道路拓扑；未保存草稿可放弃或撤销本次生成。没有添加后台独立模型轮询。


## v0.12.1 一键写入和删除工具提示词

在「设置 → AI 动态更新与 Tool Calling」的提示词下方，点击「一键写入世界书」，即可在当前单角色聊天的角色主世界书中创建并启用常驻条目「动态地图 · AI 工具使用规则」。再次点击更新同一插件标记条目，内容相同时不会重复保存。目标书名直接显示在按钮上方；没有绑定主世界书时会提示先绑定，不会自行新建书或更改角色绑定。

「删除已写入提示词」仅删除 dynamic_map_owner=dynamic-map/tool-calling-v1 的本插件条目，手动复制的同名提示词、其他条目及空条目均保留。覆盖/删除前把原条目保存到聊天元数据 dynamicMapPromptBackups（最近10份，可从聊天导出中取回）。共享同一世界书的角色共用此条目。删除提示词不会关闭原生工具开关，也不删除地图。

读写期间校验聊天和绑定书；写入前再次读取及检查宿主缓存，发现编辑冲突就停止。保存后读回校验并通知世界书更新。宿主没有原子版本写入接口，极短的检查到提交间隙仍可能发生并发修改，应避免同时编辑同一本书。写入超时会提示保存结果未确认，不宣称成功。

接口依据：[SillyTavern world-info.js](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/world-info.js)。可选浏览器回归：node scripts/lorebook-smoke.mjs（DM_PLAYWRIGHT_PATH 与其他浏览器检查相同）。
