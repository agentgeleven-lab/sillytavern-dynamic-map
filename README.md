# SillyTavern 动态地图 · 0.3.0

可拖动、可收起的地图悬浮窗，支持聊天独立保存、地点和路线编辑、JSON 备份、地图平移与节点拖动。纯 JavaScript，无第三方运行依赖，无需构建。

## 安装与更新

在酒馆「扩展 → 安装扩展」中输入：

```text
https://github.com/agentgeleven-lab/sillytavern-dynamic-map
```

已有安装可更新扩展后刷新页面。手动安装时，把完整文件夹放到 `data/<用户标识>/extensions/` 或 `public/scripts/extensions/third-party/`，确保 manifest.json 位于插件根目录，只安装一份。

## 使用

1. 打开一个聊天，点击屏幕边缘的「动态地图」浮条展开。首次使用显示青云宗、龙门市、白沙镇的示例，第一次编辑后保存到这个聊天。
2. 展开「编辑地图与备份」，选择「＋ 新增地点」，填写名称、类型和描述后保存。编辑已有地点时，从下拉框选择它；ID 保持不变。
3. 在路线表单中选择起点和终点，设置名称及是否双向。可编辑已有路线，也可新增路线。单向路线在图中有方向箭头。
4. 拖动空白处平移画布；拖动地点改变位置并标记为固定；滚轮或 −/＋ 缩放。「重置视图」适配全部已发现地点，「定位当前」居中当前地点。
5. 点击地图节点或附近地点查看详情，可设为当前位置。移动不模拟旅行时间，不限制必须沿路线通行。
6. 删除需要确认；删除地点会同时移除关联路线，若删除当前位置则清空当前位置。
7. 「导出 JSON」下载完整地图文档。「导入 JSON」支持不超过 5 MB 的有效 v1 文档，确认后替换当前聊天地图，并先触发原地图备份下载；请允许浏览器下载并确认备份落盘。导入失败或期间切换聊天不会替换数据。

## 保存方式

- 每次有效编辑、位置变更或视图操作，写入当前 `chatMetadata.dynamicMapV1` 并调用酒馆 `saveMetadata()`。切换聊天监听 CHAT_CHANGED，重新载入独立文档。
- 角色使用角色头像标识和聊天名，群聊使用群聊标识和聊天名；浏览器恢复副本另按当前用户的插件命名空间隔离。
- 保存先写浏览器恢复副本，随后同步聊天。失败时窗口会提示，可「重试保存」或立即导出。未同步副本可在下次打开该聊天时恢复；已同步缓存不会覆盖服务端数据或复活同名新聊天。
- 聊天文件携带地图；浏览器恢复副本仅属于本浏览器。聊天改名后以聊天元数据为准，尚未同步的旧名字副本不会自动迁移，请先保存成功或导出再改名。
- 不支持多个页面同时编辑同一聊天的合并；请只用一个页面编辑。
- 没有打开聊天时是只读示例，不能把它当成已保存地图。损坏的存档不会被示例覆盖，可导出原始数据，再导入有效文档恢复。
- 悬浮位置和展开状态单独保存在浏览器 UI 偏好中，不进入地图文档。可拖动标题或聚焦标题后用方向键移动，Shift 加快；「归位」或扩展设置中的「悬浮窗归位」恢复窗口位置。

## 结构与接口

```text
index.js                      酒馆初始化、聊天切换和清理
src/core/protocol.js           v1 协议与校验（graph/hex/grid）
src/core/store.js              原子更新、订阅、编辑作用域检查
src/core/selectors.js          当前位置、邻接查询和变量摘要
src/adapters/chat.js           聊天绑定、元数据保存、恢复副本
src/ui/panel.js                悬浮窗与地图控制
src/ui/editor.js               地点/路线表单与 JSON 备份
src/ui/navigation.js           平移、节点拖动、滚轮缩放
src/ui/graph.js                SVG 地点与路线渲染
src/ui/floating.js             窗口位置和折叠偏好
src/integrations/api.js        可选变量/状态栏/AI 接口
```

公共入口保持 `window.SillyTavernDynamicMap`。小白X和状态栏不是依赖；此版尚未自动同步到它们，也未注册 AI Tool Calling。hex/grid 仅支持协议，尚未实现渲染。方向约束自动布局留待后续。
