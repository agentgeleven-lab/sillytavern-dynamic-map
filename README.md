# SillyTavern 动态地图 · 0.6.2

无第三方运行依赖、无需构建的地图悬浮窗。顶部六页：查看地图、调整地图、地图规则、AI生成地图、地图模板、设置。

## 安装与更新

在酒馆「扩展 → 安装扩展」中输入：

```text
https://github.com/agentgeleven-lab/sillytavern-dynamic-map
```

已有安装可更新扩展后刷新。手动安装请把完整文件夹放入用户扩展目录，manifest.json 应位于插件根目录，只安装一份。更新前可导出已保存地图备份。

## 新的拖动逻辑

先打开角色卡的聊天，再进入「调整地图」并勾选「允许拖动地点」。

- 按住地点后可自由拖动，节点与道路预览跟随指针。
- 靠近**任意地点**都会显示它的 16 方位，虚线圈表示松手后的吸附位置，不限于原有邻居。
- 松手会吸附并连接最近的地点，断开被拖地点的其他旧连接；原地点全部保留。
- 远离所有地点时按松手坐标自由放置，并断开旧连接。
- 吸附半径为图上一段道路长度的 1.4 倍。已占用的方位会避让到最近可用方位；全不可用时给出提示。
- 继续连接其他道路，可以在「路线连接」中手动添加。每段图上道路仍等长；真实距离在地图规则中设置。

这些操作都只影响草稿。只有「保存地图」后，查看地图和对外状态接口才使用新地图。切换聊天会在本页面保留各自草稿，刷新页面会丢弃未保存草稿。

## 简洁操作页

「调整地图」下方用按钮切换当前操作，不再同时展开全部表单：

- **移动地点**：拖动说明。
- **地点资料**：选择或新增地点，编辑名称、说明、类型，设置当前位置。
- **路线连接**：选择或新增路线，设置端点、16 方位、固定道路类型和单向/双向。
- **途经点**：单独新增，或在选中道路中插入。插入把一段变两段，实际总距离增加。途经点可作岔路口。
- **删除**：删除地点及关联路线，或仅断开选中路线。未保存时可放弃草稿恢复。

「查看地图」只显示已保存地图。点击地点查看说明、相邻地点、方位、距离、道路类型、通行方式、预计时间和单向限制。拖动空白平移，滚轮缩放，「拖动后回归」适配所有节点，不改当前位置。

## 地图规则与界面设置

「地图规则」内的按钮分别管理距离、通行方式、地点类型、道路类型。类型可新增、更名、删除；正在使用的类型需要先替换后才能删除。旧存档的自定义类型会保留。新增途经点会恢复途经点类型。默认走路速度为 5 公里/小时；时间按每段距离 ÷ 速度计算，无自动寻路或旅途计时器。

「设置」中的界面选项立即生效，不修改地图和变量：

- **在消息末尾显示小型地图按钮**：控制消息末尾的「🗺 地图」按钮。点击按钮会在该消息下方展开完整地图窗口，再次点击关闭。消息内可查看、调整、保存地图，并使用规则、生成、模板和设置六页。消息窗口与悬浮窗共用当前聊天的地图草稿，关闭窗口不丢草稿；不代表历史消息时点的地图，不把内容写入聊天正文。
- **界面主题**：青绿、深蓝、浅色。主题与按钮开关保存在界面偏好中。

## 独立地图生成 API

在「设置 → 地图生成 API」配置：

1. 勾选「使用独立 API 生成地图」。
2. 填写 API 地址、API 密钥和模型名称。支持兼容 Chat Completions 的服务；地址可填基础地址、`/v1` 地址或完整的 `/chat/completions` 地址。
3. 可调整最大输出长度和超时时间，默认 4096 tokens、120 秒。总超时对酒馆模型与独立 API 都生效，包含素材读取阶段。
4. 点击「保存 API 设置」，再到「AI生成地图」生成。关闭独立 API 后使用酒馆当前模型。

配置只用于地图生成，不改酒馆的聊天模型。角色卡与世界书读取范围不变，生成结果仍需检查并「保存地图」。

密钥输入框使用密码显示。默认密钥只在当前页面会话中保留；可勾选「记住密钥（仅本浏览器）」保存到浏览器本地存储。地址、模型等配置独立保存在本浏览器。密钥不进入地图 JSON、模板、聊天元数据或模型提示词。「清除密钥」删除会话和本地保存的密钥。

请求从浏览器直接发送，服务必须允许跨域请求；此版不提供服务器代理。仅支持非流式 Chat Completions，不支持直接填写其他协议的地址。请求失败不会自动切换服务重试；HTTP 失败、网络错误、超时、空响应和截断输出都会提示且不会覆盖地图。

## AI 生成的读取范围

默认读取当前角色卡、角色主世界书、角色附加绑定世界书，以及当前聊天绑定世界书。没有绑定主世界书时兼容角色卡内嵌世界书。

可选 **“同时读取已开启的全局世界书”**：仅加入酒馆中当前已开启的全局世界书（可以未绑定角色），不会遍历全部已保存的世界书，也不会读取未开启的其他书籍。重复书籍去重；各书跳过禁用条目和空内容。读取完成后界面显示实际书名及字符数。此读取用于地图生成素材，不依赖聊天关键词触发。

读取接口参考 [SillyTavern 官方世界书模块](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/world-info.js)：主绑定使用角色 extensions.world，附加绑定使用 charLore，全局开关使用 selected_world_info。

仅在点击生成后读取素材并调用酒馆当前模型。超过 200,000 字符、书籍读取失败、聊天或草稿变化时不会覆盖地图；超长内容不会静默截断。生成结果先进入草稿，检查后再保存。当前仅支持单角色聊天，真实模型输出质量依赖模型及设定素材。角色卡与世界书不会被修改。

## 模板、保存与接口

模板保存于本浏览器，可命名存储或载入草稿。支持导出已保存地图、导出草稿、导入不超过 5 MB 的 JSON。载入/导入会替换未保存草稿，可先导出备份。

保存写入当前 chatMetadata.dynamicMapV1，先保留本地恢复副本，再调用酒馆 saveMetadata()。同步失败时可在模板页重试或导出。未同步副本可在同一浏览器恢复。已同步缓存不会覆盖聊天元数据或复活同名新聊天。损坏存档可先导出原始数据，再导入有效草稿并保存恢复。

公共入口为 window.SillyTavernDynamicMap；订阅和摘要读取已保存状态。外部 applyUpdate 仍直接更新已保存状态，若和未保存草稿冲突则拒绝草稿覆盖。暂不支持多个页面编辑同一聊天的合并。

小白X、状态栏不是依赖，目前仍为预留接口，尚未自动接入或注册 Tool Calling。graph 已渲染，hex/grid 仅预留协议。

## 检查

```sh
npm run check
npm test
```

浏览器交互回归使用可选开发工具 Playwright 和 Edge：安装 Playwright 后运行 npm run test:browser；也可设置 DM_PLAYWRIGHT_PATH 指向其 index.mjs，DM_BROWSER_CHANNEL 默认 msedge。此测试启动独立无头浏览器和本地服务器，使用模拟角色、世界书与模型，不发送真实模型请求。

独立演示：在插件目录运行 python -m http.server 8765 --bind 127.0.0.1，再打开 http://127.0.0.1:8765/demo.html。演示页模拟聊天保存；验证范围见 VALIDATION.md。



## v0.6.2 生成等待与地图命名

生成页显示“读取角色卡与世界书 / 读取某本世界书 / 等待模型返回 / 检查地图”及已等待秒数。两种模型都受总超时控制，默认 120 秒，可在设置中修改并保存。点击“取消生成”会立即停止等待，迟到结果不会修改草稿。关闭窗口也取消该窗口的生成等待。

独立 API 会收到中止信号；酒馆内部请求能否真正终止由宿主决定，插件不调用可能影响正常聊天的全局停止操作。取消/超时不是模型服务已停止计算的保证。素材较大时可先取消，再减少启用的全局书范围或改用已配置的独立 API。界面写着“使用酒馆当前模型”时，独立 API 尚未启用。

初始示例名称改为“未命名地图”。旧聊天已保存的名字保持不变；在“调整地图 → 地图名称”修改、应用后保存即可。生成提示只使用中性的结构样例，不再把旧地图的沧州/龙门市内容当作示例，要求模型按角色和世界设定命名。模型仍沿用通用示例名时，使用“角色名称 · 地图”作回退名称。
