## 可以做什么

| 功能 | 说明 |
| --- | --- |
| 🗺️ 多种地图 | 节点连线、六边形与方格；独立地图和多层子地图共存。 |
| 📍 地点与道路 | 地点说明、类型、当前位置；道路名称、可选距离、方位和单向关系。 |
| ✎ 手动编辑 | 拖动调整位置或重新连接；长短道路共存，自动整理尽量保留远近关系。 |
| ✦ AI 生成 | 按层级生成整图、追加地点与道路，或为选中地点生成内部地图。 |
| ↻ 聊天动态更新 | 支持原生 Tool Calling，也支持无需工具调用的正文更新块。 |
| ▧ 保存与模板 | 地图按聊天保存，先编辑草稿再保存；支持本地模板及 JSON 导入导出。 |
| ⚙ 可选联动 | 小白X变量摘要与世界状态栏位置联动；不安装这些插件也能使用地图。 |
| ◐ 多种入口 | 可拖动、收起的悬浮窗，或从消息末尾按钮展开地图；三种主题。 |

## 安装与上手

在 SillyTavern「扩展 → 安装扩展」中粘贴仓库地址：

```text
https://github.com/agentgeleven-lab/sillytavern-dynamic-map
```

已有安装：更新扩展，然后刷新页面。请只保留一份插件安装。

1. **打开角色卡聊天**，打开地图窗口。
2. 在 **编辑** 中创建地点与道路，或在 **AI** 页生成地图草稿。
3. 检查地图后点击 **保存全部地图调整**。
4. 在 **查看** 页点击地点，查看说明与相邻道路；有内部地图时点击详情里的入口按钮进入。

> **编辑先进入草稿。** 未保存调整不会改变查看地图和对外变量；刷新前请保存或导出草稿。

## 拖动与地图层级

在「编辑 → 移动地点」开启允许拖动地点，选择：

- **调整位置（默认）**：保留所有连接，道路随地点移动。
- **重新连接**：靠近地点松手连接它并断开其他旧路；远处松手断开旧路。拖动时显示预览。

16方位吸附保留拖出的距离，不把道路恢复为统一长度。自动整理尽量保留已有长短关系，同时处理重叠与拥挤；图上线长不改变实际距离或通行时间。

格子地图仍按空格吸附、保留道路。顶部地图选择栏切换不同地图与层级；浏览地图不会移动角色。修改角色位置需在编辑中明确设置并保存。

## AI 生成与更新

### 生成预设与 API 配置

「设置 → 生成预设」可新建、复制和编辑消息块，调整资料顺序与开关；在 AI 页选择预设并查看最近请求提示词。「生成 API」支持命名配置，分别绑定整图、追加与内部地图生成；可开启流式接收和同一聊天排队。完整结果仍先校验再进入草稿。详见[0.15.0 更新说明](CHANGELOG.md#v0150-地图生成预设与异步运行配置)。

### 生成地图

默认使用酒馆当前模型，也可在「设置 → 生成 API」配置兼容 Chat Completions 的独立 API。

- 按世界、国家、城市、园区、建筑或自定义层级生成。
- 默认读取当前角色卡与绑定世界书；可勾选读取**已开启的全局世界书**，不会遍历所有已保存书籍。
- 追加生成结合当前地图和最近30条非系统聊天，保留已有地点与道路。
- 可选择是否生成道路名称、距离；现实交通可根据模型知识补充车站、换乘点与分支连接。
- 资料不设插件字符上限，模型服务自身的上下文容量仍适用。

**目前没有联网搜索。** 模型补充的现实交通信息未经联网核实。生成结果进入草稿，需要检查后保存。

### 聊天中动态更新

在「设置 → AI 动态更新」开启地图工具，并选择更新方式：

| 更新方式 | 适用情况 |
| --- | --- |
| 原生 Tool Calling | 酒馆和聊天模型支持函数调用。 |
| 正文更新块 | 模型不支持函数调用，以约定的 JSON 更新块提交变更。 |

默认更新进入草稿，也可主动开启自动保存。设置内提供世界书提示词的一键写入、更新与删除，以及正文更新块的隐藏正则。独立生成 API 不替代酒馆聊天模型处理这些更新。

## 规则与联动

「规则」管理地点类型、道路类型、距离单位、通行方式与速度，以及格子区域、地形和行政归属。

通行方式目前用于按速度估算道路耗时，尚不能逐路限定交通方式；未填写道路距离时不估算时间。插件不执行自动寻路、候车换乘计时或跨层旅行。

可在设置中启用小白X变量摘要与[世界状态栏](https://github.com/agentgeleven-lab/world-status-hud)位置联动。地图保存后发布摘要，完整地图不会塞入变量。具体开关和更新格式见[联动说明](CHANGELOG.md#v0110-小白x变量与状态栏实际联动)。
